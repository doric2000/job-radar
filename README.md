# Job Radar: בוט שמזהה משרות ג'וניור ראשון

הבוט סורק כל ~5 דקות את לוחות המשרות הציבוריים של כ־180 חברות ישראליות (סייבר, Backend/תשתיות, בנקים, תעשיות ביטחוניות, חברות רב־לאומיות), מסנן לפי הפרופיל שלך, ושולח התראה בטלגרם **ברגע שמשרה חדשה מופיעה**.

הוא לא מגיש מועמדות. הוא מתריע ומציג למה המשרה מתאימה, כדי שתגיש אתה בקליק אחד.

## מה הוא מחפש (ברירות המחדל שהוחלט עליהן)

| נושא | הגדרה |
|---|---|
| תחומים | Backend / Systems / Full Stack, ואבטחת מידע / סייבר |
| ותק | מתחילים במפורש (Junior, Graduate, בוגר, Entry...), עד שנת ניסיון, עד שנתיים. כותרת גנרית בלי שום ציון ותק **לא** מתריעה (אפשר להפעיל בהגדרות) |
| מיקום | ישראל (משרד/היברידי), מרחוק (עולמי/EMEA/ישראל), חו״ל עם רילוקיישן |
| סוג משרה | משרה מלאה והתמחות מובנית. משרות סטודנט/חלקיות מושתקות |
| אישור בטחוני | משרות כאלה **כן** מתריעות, עם תג 🔒 |
| הגשה | התראה בלבד (בלי הגשה אוטומטית) |

הכול ניתן לשינוי ב־`config.yaml`.

## איך הבוט נמנע מלהציף או לטעות

- **הבסיס הראשוני:** בסריקה הראשונה של חברה כל המשרות הקיימות נרשמות בשקט. התראה יוצאת רק על משרה שהתאריך שלה במקור טרי (48 שעות).
- **תאריכים ישרים:** בכל התראה מצוין מקור התאריך וסוגו (פורסמה / נוצרה / עודכנה / דיוק יומי). עדכון לא מוצג כפרסום ראשון, והודעת טלגרם מסומנת כ"ליד" שצריך לאמת במקור.
- **ותק נדרש מול יתרון:** "3 שנות ניסיון יתרון" לא פוסל; "3+ שנות ניסיון" ברשימת הדרישות פוסל. נבדקים גם ניסוחים בעברית.
- **תקלה אינה סגירה:** לוח שנכשל לא "סוגר" משרות. משרה שנכשלה בשליפת פרטים תנסה שוב בריצה הבאה.
- **כפילויות:** אותה משרה בשני מקורות מתריעה פעם אחת.
- **דופק יומי:** הודעה שקטה אחת בבוקר + רשימת חברות שנכשלות ברצף.

## הקמה (כ־20 דקות)

1. **בוט טלגרם:** בטלגרם דבר עם `@BotFather`, פקודה `/newbot`, ושמור את ה־token. שלח לבוט הודעה כלשהי, ואז פתח בדפדפן `https://api.telegram.org/bot<TOKEN>/getUpdates` ומצא את `"chat":{"id":...}`.
2. **מאגר ציבורי ב־GitHub:** צור מאגר חדש, **Public** (זה מה שנותן דקות הרצה בלי הגבלה, ולכן סריקה כל 5 דקות בחינם), והעלה אליו את כל התיקייה הזו. מאגר ציבורי חושף את רשימת החברות וההגדרות, ואין בו שום פרט אישי או קורות חיים.
3. **Secrets:** ב־Settings → Secrets and variables → Actions הוסף `TELEGRAM_BOT_TOKEN` ו־`TELEGRAM_CHAT_ID`.
4. **Actions:** בלשונית Actions אשר הפעלה. בלשונית Settings → Actions → General תן ל־Workflow הרשאת **Read and write**.
5. **גילוי לוחות משרות:** Actions → `discover` → Run workflow. הוא עובר על כל החברות, מוצא את מערכת הגיוס שלהן ומאמת. בסוף יש `data/discovery_report.md` עם שלוש רשימות: נמצא, דורש בדיקה, לא נמצא.
6. **בדיקת תקינות:** בלוג של `discover` יש שלב Healthcheck שמדפיס לכל מערכת גיוס אחוז הצלחה ואחוז משרות עם תאריך ומיקום. **זו הבדיקה מול המציאות** (ראה "מה לא נבדק").
7. **הפעלה:** Actions → `scan` → Run workflow. הריצה הראשונה בונה בסיס בשקט. מכאן הוא רץ לבד.

## מה לא נבדק (חשוב)

הבוט נבנה בסביבה בלי גישה לשרתי המשרות, ולכן נבדק על נתוני דוגמה בלבד (49 בדיקות). מה שיש לאמת בהרצה הראשונה:

- **דיוק שדות ב־API:** Greenhouse, Lever, Ashby, Comeet ו־SmartRecruiters נכתבו לפי התיעוד הציבורי. **Workable, Recruitee ו־Workday** מסומנים "best-effort" בקוד.
- **Comeet:** ה־token נשלף מקוד ההטמעה בעמוד הקריירה של החברה. אם החברה לא חושפת אותו, תופיע הערה בדוח הגילוי והוא יתווסף ידנית.
- **מאגר החברות הוא זרע:** הדומיינים נכתבו מהזיכרון. מה שלא יאומת יופיע בדוח.
- **שני לוחות Workday (NVIDIA, Intel)** הוגדרו ידנית מהזיכרון.
- **תזמון של GitHub:** `*/5` הוא ניסיון, לא הבטחה. בעומס הריצה יכולה להתעכב בכמה דקות עד כמה עשרות דקות. אם הדיוק חשוב לך, אפשר להפעיל את ה־workflow מ־cron חיצוני דרך `workflow_dispatch`.
- **כיבוי אוטומטי:** במאגר ציבורי GitHub מכבה workflow מתוזמן אחרי 60 יום בלי פעילות במאגר. ה־discover השבועי עושה commit כשיש שינוי, ודופק הבוקר מתריע אם הבוט שותק.

## פקודות שימושיות (מקומית)

```bash
pip install -r requirements.txt
python -m unittest discover -s tests          # בדיקות
python -m radar.discover --only wiz,cyera     # גילוי לחברות מסוימות
python -m radar.run --healthcheck             # בדיקת שליפה מול השירותים
python -m radar.run --dry-run --all           # מדפיס התראות בלי לשלוח ובלי לשמור
```

## הוספת חברה

שורה אחת ב־`companies.yaml`, ואז להריץ `discover`. אם לחברה אתר קריירה מותאם אישית (בנקים, תעשיות ביטחוניות, גוגל/מיקרוסופט/אמזון), יופיע "not found". שם נדרש סורק ייעודי (ראה `docs/SOURCES.md`).

## הגשת מועמדות מהתראה

הבוט במאגר ציבורי לא מחזיק את קורות החיים שלך, וזה במכוון. כשמגיעה התראה מעניינת, שלח את הקישור לשיחה עם Claude יחד עם קורות החיים שלך, ובקש התאמה עובדתית של הקורות ושל מכתב קצר לפי הדרישות.

## מבנה

```
radar/filters.py      סינון: תפקיד, בכירות, ותק נדרש/יתרון, מיקום, אישור בטחוני
radar/fetchers/       סורק לכל מערכת גיוס
radar/discover.py     גילוי ואימות אוטומטי של לוחות משרות
radar/run.py          לולאת הסריקה, בסיס ראשוני, כפילויות, דופק יומי
radar/leads.py        קריאת ערוצי טלגרם ציבוריים (לידים)
companies.yaml        מאגר החברות (זרע)
docs/SOURCES.md       מאגר המקורות המורחב והמחקר
```
